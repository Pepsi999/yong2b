## 3. validate_universe.py 체크 결과 (§2.2)

전체 출력: `reports/validate_universe_output.txt`

1. **IPO 정합성 (P0)**: 플래그 0건 (큐레이션 상장일 57건 × 멤버십 구간 단위 대조).
   FB 유형(상장 전 유니버스 존재)을 자동 탐지하는 체크로, 수정 전 원장에서는 FB가 플래그됨을 확인 후 수정본에서 통과.
   티커 재사용 자동 감지 2건: SNDK(구 SanDisk 2010~2016 vs 신규 Sandisk 2025~), LMCA(구 Liberty Media 2012 vs 신 Liberty Media 2013~) → CP-2에서 가격 구간 분리 대상.
   yfinance 실측 최초 가격일 대조는 현 환경 네트워크 차단으로 미실행 → CP-2에서 커버리지 리포트에 통합 예정.
2. **거래소 정합성**: IPO 체크 플래그 0건이므로 신규 수동 확인 대상 없음. 기지 사례(VIAB: 2012-05 나스닥 이전 후 편입)는 원장에 반영 완료.
3. **쌍 정합성 (P0)**: 플래그 0건. 무짝/비대칭 화이트리스트 3건(2022-02-02 CEG, 2022-12-19 연례 6/7, 2026-07-07 SPCX)은 공식 PR 근거 명기.
4. **rename 체인 (P2)**: QRTEA(당시 LINTA/QVCA), EA(당시 ERTS)는 point-in-time 티커 불일치이나 yfinance 현행 티커가 전체 이력을 보유해 무해 — 기록만 유지. GOLD·SNDK 티커 재사용은 P1로 CP-2 태깅 목록에 등재.
